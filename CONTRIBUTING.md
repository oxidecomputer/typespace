# Contributing

## AI-assisted contributions

AI tools are fine. Your reviewer appreciates knowing if you did use AI, and if
so how you prompted it or used it. Say what you used in the PR template.
You're responsible for every line: you should be able to explain it in review.
In general, a clear issue describing a real problem you encountered is more
highly valued than a lightly-prompted PR. If you're interested in fixing your
own issue (with or without AI) please say so.

An agent working without a reviewer marks its commits with a
`Human-Review: required` trailer, and the PR gets a `requires-human-review`
label when it is opened. A maintainer removes the label after reading the diff.
